## 双 lockfile 隐患（已登记 P0）

`package-lock.json` 与 `pnpm-lock.yaml` 并存，未声明 `packageManager`，CI 走 `npm ci`。
install 不会挂，但 pnpm-lock 更新；日后若有人用 pnpm，两棵依赖树会**静默分叉而 CI 不报错**。
建议二选一（保留 npm 就删 pnpm-lock.yaml 与 package.json 里遗留的
`pnpm.onlyBuiltDependencies`）。
