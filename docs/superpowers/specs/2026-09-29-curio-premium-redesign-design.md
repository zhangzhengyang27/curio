## 1. 背景与诊断

用户判断项目「代码质量与页面设计均为 demo 级」,要求重塑为大厂级别。

**诊断结论**(2026-09-29 代码走查): 底子不是 demo——
`src/styles/theme.css` 已有 Material 3 风格令牌体系(亮/暗双模式、色彩角色、间距/圆角/字阶/动效/阴影/焦点环);两条外壳已物理分离;首页「全幅地球 + 玻璃拟态浮层」的布局范式与一线地球产品同构;`useThemeStore` 已实现**暗色默认**(首访无偏好直接进暗色)。

真正的「demo 感」来源是**设计的最后 20% 没有定义到组件层与页面层**: 面板、按钮、加载/空/错误态、动效节奏、排版密度、层级关系各自为政,没有统一的组件级视觉语法。大厂与 demo 的分界线在这里。

### 目标

- **G1** 全站统一的高级暗色体验(对标 Linear / Vercel / AntV L7 官网质感),地球是唯一主角;
- **G2** 设计语法落进组件层(GlassPanel / 按钮体系 / 状态三件套 / Tooltip),后续新页面有章可循;
- **G3** 代码质量线: `tv-` 前缀残留清零、`EarthView.vue` 拆分、内联样式收敛到令牌。

### 非目标(范围冻结)

- **1421 个示例组件一律不改**(只重塑画廊壳层);不接新示例源;
- 不做移动端适配(项目已拍板 PC-only,`min-width: 1024`);
- 不引入第三方组件库或新的重型运行时依赖(维持零重型依赖策略);
- 不动 `EarthCanvas` 的 Three.js 渲染内部(只重塑其外围壳层与编排)。

## 3. 设计原则(贯穿所有里程碑)

1. **暗色为品牌基调**(现状即暗色默认,本设计把它做精),亮色保留为次要模式,**两套都必须过 4.5:1 静态对比度**;
2. **地球是唯一主角**: chrome(顶栏/面板/控件)退后——近黑表面、低饱和、克制发光;
3. **一种面板语法**: 全站浮层/卡片/弹层收敛到一套容器体系,统一圆角、描边、模糊与内边距;
4. **动效有语法**: 所有动画必须引用令牌,禁止裸秒数;进场、悬停、状态切换各有固定模式;
5. **状态完整**: 每个数据界面必须有加载/空/错误三态,禁止裸转圈。

## 4. 设计系统 v2(令牌层规范)

在 `theme.css` 现有 M3 架构上**升级而非推倒**。所有新令牌用 `--cu-` 前缀;改动后必须跑 `node scripts/verify-theme-tokens.mjs --update` 收紧棘轮基线(`scripts/_theme_token_baseline.json` 只允许下降)。

### 4.1 色彩

- **深空黑四阶表面**: 将暗色背景从「单一色 + 半透明容器」重校准为 0→3 递亮四阶(0=页面底,3=最高浮层)。实现上**优先复用现有 `--cu-surface-container-*` 角色**、调整其值,不新增平行体系;起始值以现有 Deep Space 靛蓝夜空为基微调,**最终值以 M1 对比度实测为准**(这是调优过程,不是未决项;闸门是硬的)。
- **强调色**: 主 accent 保持蓝系并针对暗色提亮提饱和;新增**数据语义色板** `--cu-data-*`(地震/图层/轨迹/基线等 6 色左右),每色在两种主题下都过对比度。数据色只用于数据本身(标记、折线、数字高亮)。
- **发光**: 新增 `--cu-glow-sm/md/lg` 三档。允许使用的场景白名单: 主 CTA 悬停、active 段控、地球交互反馈、关键数字;**禁止大面积铺光**。
- **文字阶**: 主文字近白且保持靛蓝色相;次级文字实测 ≥4.5:1;禁止用透明度黑造灰字。

### 4.2 高程(暗色优先策略)

暗色下层级表达 = **表面色阶 + 1px 内描边(`--cu-outline-variant`)+ 可选 glow**;`--cu-shadow-*` 降权,仅用于亮色模式与浮层投影。这是暗色 UI 的通行做法,也是「高级感」的主要来源之一。

### 4.3 排印

- 字阶: 现有 `--cu-fs-xs~3xl` 保留;新增展示级 `--cu-fs-display-1: 48px`、`--cu-fs-display-2: 64px`(数据大数字、空态文案);
- 字重收敛为 400/500/600/700 四档,界面标题 600 起(现状 700 偏重是廉价感来源之一);
- 数字: `.tv-num` 改名 `.cu-num`(tabular-nums);数据大数字 = display 字阶 + 数据语义色。

### 4.4 密度 / 圆角 / 间距

- 面板内边距三档新令牌: `--cu-pad-compact: 12px` / `--cu-pad: 16px` / `--cu-pad-loose: 24px`;
- 4px 网格与现有间距令牌不变;圆角阶梯不变: 面板 `radius-lg(12px)`、控件 `radius-md(6px)`。

### 4.5 动效

- 新增 `--cu-dur-slow: 400ms`(页面/面板进场);`--cu-dur-fast 150ms`(悬停/按压)、`--cu-dur 250ms`(展开/切换)沿用;缓动统一 `--cu-ease`;
- 固定模式: 面板进场 = fade + translateY(8px),多面板以 **60ms stagger** 错峰;
- ESLint 层面不加新规则,但 code review 闸门:`<style>` 中出现裸 `transition: ... 0.2s` 视为不合规。

### 4.6 无障碍

- 统一焦点环保留;`::selection`、滚动条样式保留;
- 两主题全量静态对比度 ≥4.5:1,`verify:theme` 零容忍、不进基线;刻意例外必须上一行 `/* theme-tokens:allow */`。

## 5. 组件语法(新增基础组件,零依赖)

新组件放 `src/components/ui/`,**只做视觉语法、不带业务**。落地后页面禁止再手写玻璃面板样式。

| 组件 | API 草案 | 替代什么 | 主要使用处 |
|---|---|---|---|
| `GlassPanel.vue` | `density: 'compact'\|'cozy'\|'loose'`、`interactive?: boolean` | `.tv-glass-panel` class 的 50 处散用 | 首页浮层、平台卡片、画廊侧栏 |
| `CuButton.vue` | `variant: 'primary'\|'ghost'\|'icon'`、`size: 'sm'\|'md'`、`loading?: boolean` | 各页面裸 `<button>` | 全站动作 |
| `EmptyState.vue` / `ErrorState.vue` / `LoadingSkeleton.vue` | `icon?`、`title`、`description?`、`action?` | 裸转圈、`v-if` 空判断 | 平台四页、画廊 |
| `CuTooltip.vue` | 触发式浮层,支持 `kbd` 快捷键标注 | 原生 `title` 属性 | Toolbar、顶栏 |
| `UiIcon.ts` | 沿用 | — | 补齐图标统一 1.5px 笔画宽度 |

## 6. 页面重塑范围

### 6.1 顶栏(两壳共用 `ShellNav`)

- active 态从「border-bottom 下划线」升级为 **pill 段控**(`surface-container-high` 底 + 主文字色),hover 走 `--cu-dur-fast` 过渡;
- 品牌区规范化: logo 32px 保留,名字与 tag 的间距/字重按排印规范;
- **类名冻结**: `.app-nav`、`.nav-search`、`.search-input`、`.nav-dropdown` 等一律不改名——`perf.spec.ts` 以 `.app-nav` 为首页 ready 选择器、`smoke.spec.ts` 以 `.nav-search .search-input` 区分顶栏搜索(见 `shell-nav.css` 头注释)。

### 6.2 首页地球(`EarthView` 壳层,不动 `EarthCanvas` 内部)

- 中央搜索升级为**命令面板**: `⌘K`(及 `/`)唤起,结果分组 = 地点(复用现有 `SearchBox` 逻辑)/ 图层 / 工具,键盘上下选择、回车执行;
- 四组浮层(LayerPanel / InfoPanel / Toolbar / 底部模式条)统一换 `GlassPanel(density='cozy')`,间距走统一 gutter;
- Toolbar 按钮全部换 `CuTooltip` + 快捷键标注,按「截图 / 视图 / 地球效果 / 巡游」分组加分隔线;
- 底部 viz 模式条改分段控件样式,loading 态用 `CuButton` 的 loading;
- **进场编排**(第一眼大厂感的核心): 地球先入,四组浮层 60ms stagger 跟进,走 `--cu-dur-slow`;
- **首屏闪白修复**: `index.html` 增加 pre-hydration 内联脚本,按 localStorage 偏好预置 `html.dark`,消除主题闪烁。

### 6.3 平台四页(tools / analysis / monitor / workbench)

- 统一 `PageHeader`(标题 + 一句描述 + 右侧动作区);
- 卡片栅格: 12 列、最小卡宽 240px、统一 gutter;
- 加载/空/错误三态组件全覆盖;统计数字用 `.cu-num` + display 字阶 + 数据语义色。

### 6.4 示例库壳层(不动 1421 个组件)

- `ExampleCard` 暗色质感: 截图容器统一 16:10 比例、hover 微升(过渡走 `--cu-dur`;暗色下层级表达按 4.2 用色阶 + 描边,不加重投影);
- 筛选侧栏 `GlassPanel` + 分组化;分页控件统一 `CuButton(ghost)`;
- `ResourceShell` 顶栏同步 6.1 的改造。

## 7. 代码质量线(渐进式)

### 7.1 `tv-` → `cu-` 全量清零

2026-09-29 实测: **70 处 / 35 个文件**(`grep -E '\btv-[a-z0-9-]+'` 统计)。分三类处理:

| 类别 | 明细 | 处理 |
|---|---|---|
| 纯样式类(机械改名) | `tv-glass-panel`(50)、`tv-num`(9)、`tv-card-hover`(2) | 直接改名,同步改 `theme.css` 定义处 |
| 有状态键(需迁移) | `tv-theme`(localStorage 键,2 处) | 改为 `cu-theme`,init 时读旧键迁移一次 |
| 可能被引用的 DOM 钩子(先查再改) | `tv-echarts-full`、`tv-map-bookmarks`、`tv-map-annotations`、`tv-monitor-status-v2`、`tv-html-anchor` 等 | 改名前先 grep 测试/脚本/字符串引用,确认无引用再改 |

完成后跑 `verify:theme --update` 收紧基线。

### 7.2 `EarthView.vue`(706 行)拆分

目标: 单文件 <300 行。拆出: `VizModeBar.vue`(底部模式条)、浮层编排容器、`useCommandPalette.ts`(命令面板状态机)。**E2E 断言不改**(选择器冻结),拆分以行为等价为验收。

### 7.3 内联样式收敛

基础组件落地后逐页替换内联样式;新增 CSS 一律走令牌,新硬编码色值零容忍(棘轮看守)。

## 9. 关键约束与不变量(实施时不可违反)

- E2E 选择器冻结: `.app-nav`、`.nav-search .search-input` 等 `shell-nav.css` 头注释列明的类名不改名;
- `verify:theme` 是棘轮: `--update` 只用于收紧,不允许用来让失败消失;
- E2E 端口 `E2E_PORT`(默认 5299)+ `--strictPort`;typecheck 独占跑,报 TS6053 先怀疑并发负载;
- PC-only,`min-width: 1024` 不动;不引入第三方组件库;
- 1421 个示例组件与 registry 体系不碰(不触发 R1–R3 类风险)。

## 11. 留给实施期的两个有界决策点

1. **亮色模式是否同步重校准**: M0 审计后按「亮色现状质量」定——只保证过对比度闸门,或做与暗色同级的精修;
2. **命令面板的生效范围**: 仅首页,或两条壳层全局可用(涉及 `ResourceShell` 搜索职责边界)——M2 样板页实现时按最小范围(仅首页)先落地,扩全局另立决策。
