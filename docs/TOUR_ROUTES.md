## 0. 技术基线（已核实，分镜以此为准）

- **可视化模式为互斥切换制**：`switchVisualization(mode)`，可用模式
  `gdp / population / carbon / trade / flights / earthquake / nightlights / china / landmarks / heatmap`
  （`src/three/layers/VisualizationLayer.js`）。异步竞态已有递增序列号防护，连续自动切换安全。
  `china` 模式自带 `flyTo(104, 35)`。
- **相机**：`flyTo(lon, lat, duration)`，缓动 easeInOutCubic；**距离固定 2.5R，不支持变焦**
  （`useCameraFlight.js`）。分镜按固定距离设计；如以后要推近/拉远，需给 `flyTo` 加 distance 参数。
- **排除**：`heatmap`（mock 数据）与 `import`（需用户手动导入）不用于巡游；
  疫情（disease）按拍板排除。

**每步 schema**（借鉴 KML Tour 的 FlyTo / Wait / AnimatedUpdate 三原语）：

```json
{
  "id": "global-overview",
  "title": "全球数据全览",
  "steps": [
    { "mode": "population", "camera": { "lon": 30, "lat": 45 },
      "flyDuration": 2500, "dwell": 8000,
      "caption": { "title": "80 亿人的分布", "text": "…" } }
  ]
}
```

## 实现形态（确认分镜后开工）

- **入口**：Toolbar 新增「巡游」按钮 → 路线选择浮层（四条路线卡片）。
- **播放器**：底部播放条（路线名 / 进度点 / 上一步 / 播放暂停 / 下一步 / 退出）+
  字幕卡；`Esc` 退出，`←` `→` 步进；播放中用户拖拽地球即自动暂停。
- **URL 状态**：`?tour=<id>&step=<n>`，可刷新续播、可分享（复用画廊 URL 状态机经验）。
- **数据**：路线 = `src/three/tours/*.json`，与引擎解耦；文案只改 JSON。
- **质量闸门**：巡游引擎与路线数据全部懒加载，不进首屏 bundle（`tests/perf.spec.js` 守住
  533 KB 基线）；先补「播放/暂停/步进/URL 恢复」E2E 再实现，dev + preview 双跑。
